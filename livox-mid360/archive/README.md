# 本次现场恢复命令留档

`session-scripts/` 保存本次恢复过程中实际使用的部分命令，帮助复盘构建和退出修复。它们不是从零安装教程，也不是一键重建工具。

这些脚本可能依赖：

- 当时 `/dev/shm/livox-recovery-xin` 中的干净编译器和 sysroot。
- 已解压完成的私有 ROS、Ubuntu 依赖。
- 已存在的源码副本和特定旧文本。
- 用户名 `xin` 和固定安装路径。

重启后 RAM 目录会消失。部分补丁脚本只允许在未修改过的对应源码上执行一次，重复执行会主动报错。日常使用请按主 README 启动已安装的驱动。

依赖已经撤销的临时 SSH 密钥的远程控制脚本没有收入此目录。
